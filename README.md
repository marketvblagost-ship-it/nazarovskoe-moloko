# Назаровское молоко — GitHub Pages

Готовая статическая версия сайта. Сборка на сервере не требуется.

## Публикация

1. Загрузите **содержимое этой папки** в корень репозитория GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`, затем нажмите **Save**.

Сайт работает как в корневом домене, так и в подпапке вида `username.github.io/repository/`.

## Важно

- Ручной выбор RU / EN / 中文 и автоматический выбор по языку браузера работают без сервера.
- Определение языка именно по IP на GitHub Pages невозможно без отдельного геолокационного сервиса или CDN-функции.
- Кнопки звонка используют ссылки `tel:`, декларации скачиваются из папки `docs`.
